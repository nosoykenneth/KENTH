# 0.1 — Actividad práctica: aplicar el ciclo de decisión

## Objetivo
Practicar el ciclo escuchar → diagnosticar → decidir → actuar → verificar en tres cambios concretos, documentando el porqué de cada uno.

## Materiales necesarios
Un DAW, una mezcla o multipista sencilla (propia o de una librería gratuita de práctica), y un cuaderno o archivo de texto para anotar decisiones.

## Preparación
Abre el proyecto y escucha la mezcla completa una vez sin tocar nada. Ajusta el volumen de monitoreo a un nivel cómodo y mantenlo constante durante toda la actividad. Prepara una referencia si la tienes.

## Pasos
1. Escucha e identifica tres problemas concretos. Escríbelos como diagnósticos (elemento + momento + cualidad).
2. Para cada problema, formula una decisión en forma de hipótesis ("voy a... para que...").
3. Aplica una sola acción por problema, con una herramienta.
4. Verifica cada cambio con bypass, igualando el volumen. Anota si mejoró, empeoró o fue neutro.
5. Conserva solo los cambios que pasaron la verificación; deshaz el resto.

## Qué debe entregar el estudiante
Un documento breve con: los tres diagnósticos, la decisión/hipótesis de cada uno, la acción aplicada, el resultado de la verificación y la decisión final (conservar/deshacer). Opcionalmente, el proyecto o un bounce corto.

## Criterios de revisión
Se evalúa la claridad del diagnóstico, la coherencia entre diagnóstico y acción, la verificación con niveles igualados y la honestidad al deshacer cambios que no ayudaron.

## Errores frecuentes
Diagnósticos vagos ("suena mal"). Aplicar varias acciones por problema. Comparar a distinto volumen. Conservar cambios sin verificar.

## Versión básica
Trabaja solo con nivel (volumen de pistas): identifica tres desequilibrios de volumen y corrígelos aplicando el ciclo. No necesitas EQ ni compresión.

## Versión avanzada
Incluye una decisión de EQ y una de dinámica, documentando por qué cada una y verificando con referencia además del bypass.

## Adaptación si solo tienes auriculares
Perfecto para esta actividad: el ciclo no depende del sistema. Mantén un volumen moderado y toma descansos cada 15–20 minutos para evitar fatiga. Verifica también en mono si tu software lo permite.

## Adaptación si usas FL Studio
Usa el mezclador (Mixer): enruta cada instrumento a su pista de mezcla, usa el botón de bypass de cada efecto para las comparaciones y la automatización de volumen de pista para los ajustes de nivel. El Playlist te permite marcar el momento de cada problema.

## Adaptación si usas otro DAW
En Ableton, Logic, Reaper o Cubase el principio es idéntico: usa el bypass de cada dispositivo/plugin para el A/B, iguala el fader de utilidad o el gain para no comparar a distinto volumen, y usa marcadores para señalar los momentos diagnosticados.
