# 0.1 — Manifiesto de recursos

## Recursos textuales recomendados
El contenido canónico y el glosario de esta lección son suficientes como base teórica. Recurso adicional opcional: una plantilla de "bitácora de decisiones" (documento de texto) para registrar diagnóstico, acción y verificación.

## Recursos de audio recomendados
Una multipista sencilla de práctica (voz, batería, bajo, un instrumento armónico). Puede provenir de una librería gratuita de multipistas. No se incluye ningún WAV en este corpus; debe conseguirse aparte.

## Recursos de proyecto DAW recomendados
Un proyecto base con las pistas ya importadas y nombradas, sin procesar, para que el alumno se centre en decidir. El autor debe crearlo; no existe todavía.

## Imágenes/diagramas recomendados
Un diagrama del ciclo de cinco pasos (escuchar → diagnosticar → decidir → actuar → verificar) en forma de bucle.

## Qué debe generar el autor
La plantilla de bitácora de decisiones (texto), el proyecto DAW base y el diagrama del ciclo. Ninguno existe aún; son tareas de producción.

## Qué debe buscar en internet
Una multipista de práctica con licencia adecuada (ver recursos externos de la sección). No descargar aquí.

## Qué debe ser visible al estudiante
La plantilla de bitácora, el proyecto base y el diagrama del ciclo son visibles y útiles para el alumno.

## Qué debe ser indexable
Todas las descripciones textuales de este manifiesto son indexables. Los archivos binarios (audio, proyecto, imagen) no se indexan directamente; se indexan sus descripciones.

## Descripción textual indexable de cada recurso no textual
- **Diagrama del ciclo (imagen):** representa un bucle con cinco nodos —escuchar, diagnosticar, decidir, actuar, verificar— y una flecha de retorno desde verificar hacia escuchar, indicando que el proceso se repite.
- **Proyecto DAW base (archivo de proyecto):** sesión con pistas de voz, batería, bajo e instrumento armónico importadas, nombradas y sin procesar, lista para aplicar el ciclo de decisión.
- **Multipista de práctica (WAV/stems):** conjunto de pistas individuales de una canción corta para practicar diagnóstico y verificación; se obtiene de una librería externa con licencia de práctica.
- **Plantilla de bitácora (texto):** tabla con columnas diagnóstico, hipótesis, acción, resultado de verificación y decisión final.
